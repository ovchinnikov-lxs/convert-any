# Convert Any

Конвертер файлов, который работает полностью в браузере: файлы не загружаются на сервер,
обработку выполняет [ffmpeg.wasm](https://ffmpegwasm.netlify.app/) на устройстве пользователя.

## Что умеет

- **Изображения**: PNG, JPG, WebP, GIF, BMP, TIFF, ICO — качество, lossless WebP, изменение размера
  (проценты / вписать в рамку / точный), удаление EXIF. Анимированные GIF → анимированный WebP.
- **Видео**: MP4, WebM, MOV, MKV, AVI, GIF и извлечение звука (MP3, M4A, OGG, WAV) — сжатие по качеству
  или до заданного размера файла, разрешение, FPS, обрезка по времени, удаление звука.
- **Документы** (pdf.js, pdf-lib, pdfmake, mammoth, SheetJS — всё грузится только при необходимости):
  - DOCX / Markdown / HTML / TXT / таблицы / картинки → **PDF** (настоящий текст с кириллицей);
  - PDF → PNG / JPG (страницы, несколько — в ZIP), TXT, Markdown;
  - PDF → PDF: выбор страниц, поворот, сжатие (без потерь или растеризацией в JPEG);
  - объединение нескольких файлов в один PDF;
  - DOCX → Markdown / HTML / TXT; Markdown / HTML / TXT → DOCX;
  - XLSX / XLS / ODS / CSV / JSON — между собой (CSV с выбором разделителя и BOM для Excel).
- **Сравнение до/после** для изображений и видео: шторка, переключение, рядом; зум до пикселей,
  покадровый просмотр видео.
- **Офлайн-режим (PWA)**: сайт можно установить как приложение; после кнопки «Скачать для офлайна»
  всё работает без интернета.
- **Умное сжатие видео**: показывает кодек/разрешение/битрейт исходника, не даёт файлу вырасти
  (битрейт видео и звука не выше исходного), предупреждает, если исходник уже сильно сжат.


## Разработка

```bash
npm install
npm run dev     # копирует ядро ffmpeg в public/ffmpeg и запускает Vite
npm run build   # сборка в dist/
```

## Как добавить новую категорию

Опишите объект `Category` (см. `src/categories/image.ts` и `document.ts`): список форматов
(`from` — из каких расширений можно получить формат), поля настроек (`fields` — слайдеры, селекты,
чекбоксы и т.д. рисуются автоматически) и либо `buildArgs` (аргументы ffmpeg), либо `convert`
(свой JS-конвертер). Затем добавьте его в `src/categories/index.ts`.

## Ограничения

- Многопоточный ffmpeg.wasm (~2× быстрее) включается, когда страница изолирована заголовками
  COOP/COEP (см. `vercel.json`); иначе и при сбоях — однопоточный. Всё равно медленнее нативного ffmpeg.
- Память WebAssembly ограничена (~2 ГБ), очень большие видео могут не обработаться.
- WebM кодируется в VP8 — VP9 в текущей сборке ffmpeg.wasm падает.
- PDF → DOCX не поддерживается (качественно это делается только серверными инструментами).
  Сложная вёрстка DOCX (колонтитулы, колонки, обтекание) при переводе в PDF упрощается.
