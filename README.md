# Convert Any

Конвертер файлов, который работает полностью в браузере: файлы не загружаются на сервер,
обработку выполняет [ffmpeg.wasm](https://ffmpegwasm.netlify.app/) на устройстве пользователя.

## Что умеет

- **Изображения**: PNG, JPG, WebP, GIF, BMP, TIFF, ICO — качество, lossless WebP, изменение размера
  (проценты / вписать в рамку / точный), удаление EXIF. Анимированные GIF → анимированный WebP.
- **Видео**: MP4, WebM, MOV, MKV, AVI, GIF и извлечение звука (MP3, M4A, OGG, WAV) — сжатие по качеству
  или до заданного размера файла, разрешение, FPS, обрезка по времени, удаление звука.
- Аудио, документы, архивы — запланированы (вкладки «скоро»).

## Разработка

```bash
npm install
npm run dev     # копирует ядро ffmpeg в public/ffmpeg и запускает Vite
npm run build   # сборка в dist/
```

## Как добавить новую категорию

Опишите объект `Category` (см. `src/categories/image.ts`): список форматов, поля настроек
(`fields` — слайдеры, селекты, чекбоксы и т.д. рисуются автоматически) и функцию `buildArgs`,
возвращающую аргументы ffmpeg. Затем добавьте его в `src/categories/index.ts`.

## Ограничения

- Используется однопоточная сборка ffmpeg.wasm: видео кодируется медленнее, чем нативным ffmpeg.
- Память WebAssembly ограничена (~2 ГБ), очень большие видео могут не обработаться.
- WebM кодируется в VP8 — VP9 в текущей сборке ffmpeg.wasm падает.
